How It Works

時間が経つと猫が登場、
画面を占領して強制的に休憩を促します。

※他のタブに移動すると計測はリセットされます。

01

SNSを選ぶ

対象にしたいSNSを選びます
X / Threads / Reddit
Facebook / YouTube / Bluesky

02

時間を決める

猫が現れる時間と
居座る時間を設定します
初期設定は60分使用、5分休憩です

03

休憩する

カウントダウンが終わるまで
猫がページを占領します
メニューを開いて退いてもらうことも可能です
